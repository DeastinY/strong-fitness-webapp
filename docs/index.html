Quick install · no build needed

# 1. grab the compose file curl -O https://raw.githubusercontent.com/DeastinY/strong-fitness-webapp/main/docker-compose.ghcr.yml # 2. drop in your workout CSV cp your-export.csv data.csv # 3. run docker compose -f docker-compose.ghcr.yml up -d
Features

Everything in one place

📈

Progress charts

Volume trend, muscle group breakdown, and monthly load — filtered by year or viewed all time.

🏆

Personal records

All-time PR table with best weight, estimated 1RM, and the date each record was set. Sortable and searchable.

📅

Consistency heatmap

Workout calendar and 12-week heatmap to see streaks and training frequency at a glance.

🏃

Cardio tracking

Distance and duration per session plotted alongside strength volume for a complete training picture.

🔍

Per-exercise detail

Drill into any exercise for a full history: best weight, estimated 1RM trend, and session-by-session volume.

📤

AI export

One-click compact 3-month log you can paste straight into an LLM to get programming feedback.

Printable trainer reports

Generate a PDF-ready progress report for any date range and hand it to your coach before the next session.

  • Overview: sessions, volume, avg duration, frequency
  • Attendance calendar across all selected months
  • All-time monthly load chart with selected range highlighted
  • Per-exercise: progress chart, set-by-set table with weight deltas
  • Print via browser — no extra tools needed
